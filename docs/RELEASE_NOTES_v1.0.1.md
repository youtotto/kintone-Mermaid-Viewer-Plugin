# Mermaid Viewer v1.0.1

修正リリースです。設定の変更や再設定は不要です。プラグインを更新するだけで適用されます。

## 修正

- Mermaid の構文エラーがある図によって、後続の図まで表示されなくなる問題を修正しました。
- 構文エラー時に、不要な Mermaid のエラー表示がページ上に残る問題を修正しました。
- ホイールズームが二重に適用され、1回の操作で拡大しすぎる問題を修正しました。
- ライブラリの読み込みに失敗したときに、待機状態が続くことがある問題を修正しました。
- 削除済みのフィールド／スペースを含む既存設定が、設定画面を開いて保存した際に意図せず失われる問題を修正しました。該当する設定は「現在使用できないフィールド／スペース」と表示され、内容はそのまま保持されます。

## 改善

- Mermaid のセキュリティ設定を `strict` に変更しました。図の中の `click` によるスクリプト実行などは無効になります。
- 「全体表示」「＋」「−」の操作ボタンを追加しました。拡大や移動で図を見失っても、「全体表示」で最初の表示に戻せます（全画面表示でも利用できます）。
- グループ内に配置したスペースを、描画先として選択できるようになりました。
- 構文エラーは図ごとに表示され、他の図には影響しません。エラーの枠には行番号などの簡単な手がかりを表示します。
- 読み込み中の表示と、ライブラリを読み込めなかった場合の表示を追加しました。

## その他

- 図をダブルクリックしても拡大しないようにしました。
- 動作を検証する回帰テストを追加しました。
